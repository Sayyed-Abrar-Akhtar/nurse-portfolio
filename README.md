# Maya Thompson, RN

A standalone, responsive Next.js theme starter for the nurse industry.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Import this repository into Vercel. Framework preset: Next.js. No environment variables are required for the demo.

## Before going live

- Replace the demo name, contact email and copy in `app/page.jsx`.
- Replace the Unsplash demo image with client-owned/licensed photography.
- Set the canonical domain and social image in `app/layout.jsx`.
- Connect real booking, enquiry, commerce or CRM functionality as required.

This repository is intentionally independent from the other theme demos.
